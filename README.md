# ETF Radar

แผนลงทุน ETF ตามอายุ บอกว่าเดือนนี้ซื้ออะไร เท่าไร พร้อมพอร์ตส่วนตัวของแต่ละคน

- หน้าเว็บ: GitHub Pages จากโฟลเดอร์หลักของ repo นี้
- ล็อกอินและเก็บพอร์ต: Firebase Authentication (อีเมลและรหัสผ่าน) และ Cloud Firestore (`users/{uid}`)
- ราคา: `quotes.json` อัปเดตอัตโนมัติวันละ 2 รอบ (06:47 และ 12:47 น. วันอังคาร–เสาร์)

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด ค่า `FIREBASE_CONFIG` อยู่ท้ายไฟล์ |
| `quotes.json` | ราคา ETF หุ้น และอัตราแลกเปลี่ยน ห้ามแก้ด้วยมือ งานอัตโนมัติเขียนทับ |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล วางใน Firebase Console → Firestore → Rules |
| `manifest.webmanifest`, `icon-*.png` | ไอคอนและการเพิ่มลงหน้าจอโฮมบน iPhone |

ข้อมูลในหน้านี้เพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน
