นโยบายความเป็นส่วนตัว

ETF Radar · มีผลตั้งแต่ 25 พฤศจิกายน 2569

สรุปสั้น ๆ

  • เก็บเท่าที่จำเป็นเพื่อแสดงแผนและพอร์ตของคุณ ไม่ขายข้อมูล ไม่มีโฆษณา
  • ผู้ใช้คนอื่นเปิดดูข้อมูลของคุณไม่ได้ แต่ผู้ดูแลระบบเข้าถึงฐานข้อมูลได้ในทางเทคนิค
  • คุณดาวน์โหลดหรือลบบัญชีและข้อมูลทั้งหมดเองได้ทุกเมื่อในแท็บพอร์ต
  • ไม่ต้องกรอกชื่อจริง เลขบัญชี หรือเลขบัตรใด ๆ

1. ใครดูแลข้อมูล

ผู้ดูแลระบบ ETF Radar เป็นเจ้าของโปรเจกต์ Firebase ที่เก็บข้อมูลและเป็นผู้ตัดสินใจว่าเก็บข้อมูลไปเพื่ออะไร หากมีคำถามหรืออยากใช้สิทธิ์ที่ระบุด้านล่าง ให้ติดต่อผู้ดูแลระบบผ่านช่องทางที่ส่งลิงก์นี้ให้คุณ

2. ข้อมูลที่เก็บ

  • บัญชี: อีเมล และการยืนยันอีเมล (หากสมัครด้วยรหัสผ่าน รหัสผ่านถูกจัดการโดย Firebase Authentication ผู้ดูแลระบบมองไม่เห็นรหัสผ่านของคุณ) หรือข้อมูลบัญชี Google พื้นฐานหากเข้าด้วย Google
  • ข้อมูลที่คุณกรอก: อายุ อายุเกษียณ เงินลงทุนต่อเดือน ระดับความเสี่ยง เป้าหมาย รายการสินทรัพย์ที่ถือและจำนวน ต้นทุนและวันที่ซื้อ ปันผลที่บันทึก มูลค่าพอร์ตย้อนหลัง และการตั้งค่าเตือนซื้อรายเดือน
  • ในเครื่องของคุณ: แอปเก็บสำเนาข้อมูลเดียวกันในที่เก็บข้อมูลของเบราว์เซอร์ เพื่อให้ใช้งานได้เร็ว ข้อมูลนี้ถูกล้างเมื่อออกจากระบบหรือเปลี่ยนบัญชี

3. ใช้ข้อมูลเพื่ออะไร

เพื่อคำนวณและแสดงแผนลงทุน พอร์ต กำไร/ขาดทุน และซิงก์ข้อมูลระหว่างเครื่องของคุณเท่านั้น ไม่ใช้เพื่อโฆษณา ไม่ขายหรือแบ่งปันให้บุคคลที่สามเพื่อการตลาด

4. ที่เก็บข้อมูลและบริการที่เกี่ยวข้อง

  • Google Firebase (Authentication และ Cloud Firestore) เก็บบัญชีและข้อมูลของคุณ ตั้งค่าไว้ที่ศูนย์ข้อมูลสิงคโปร์ Google เป็นผู้ให้บริการโครงสร้างพื้นฐาน และอาจประมวลผลข้อมูลนอกประเทศไทย
  • GitHub Pages ใช้เผยแพร่หน้าเว็บ ราคาอัปเดตโดยงานอัตโนมัติฝั่ง GitHub ซึ่งไม่เกี่ยวข้องกับข้อมูลของผู้ใช้
  • Google Fonts โหลดฟอนต์ของหน้าเว็บ ทำให้ Google ได้รับที่อยู่ IP ของคุณตามปกติของการโหลดฟอนต์

5. ใครเข้าถึงข้อมูลได้

กฎความปลอดภัยของฐานข้อมูลอนุญาตให้เฉพาะเจ้าของบัญชีที่ยืนยันอีเมลแล้วอ่านและแก้ข้อมูลของตนเอง ผู้ใช้คนอื่นเข้าถึงไม่ได้ อย่างไรก็ตาม ผู้ดูแลระบบในฐานะเจ้าของโปรเจกต์ Firebase มีสิทธิ์เข้าถึงฐานข้อมูลในทางเทคนิค เพื่อดูแลและแก้ไขปัญหาของระบบ

6. สิทธิ์ของคุณ

  • ดูและดาวน์โหลดข้อมูล: แท็บพอร์ต → บัญชีของฉัน → "ดาวน์โหลดข้อมูลของฉัน"
  • ลบข้อมูล: แท็บพอร์ต → บัญชีของฉัน → "ลบบัญชีและข้อมูลทั้งหมด" ระบบลบเอกสารข้อมูลและบัญชีผู้ใช้ทันที และไม่สามารถกู้คืนได้
  • ถอนความยินยอม: ลบบัญชีตามข้างต้น หรือติดต่อผู้ดูแลระบบ
  • แก้ไขข้อมูล: แก้ได้เองในแอปทุกเมื่อ

7. ระยะเวลาเก็บ

เก็บจนกว่าคุณจะลบบัญชี

8. ความปลอดภัย

การเชื่อมต่อเข้ารหัส (HTTPS) และต้องยืนยันอีเมลก่อนเข้าถึงข้อมูล ไม่มีระบบใดปลอดภัยสมบูรณ์ โปรดใช้รหัสผ่านที่ไม่ซ้ำกับบริการอื่น

9. ข้อมูลเพื่อการศึกษา

ตัวเลขและแผนในแอปเป็นข้อมูลเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน การลงทุนมีความเสี่ยง ผลตอบแทนในอดีตไม่รับประกันอนาคต

10. เด็กและเยาวชน

แอปไม่ได้ออกแบบสำหรับผู้ที่อายุต่ำกว่า 18 ปี

11. การเปลี่ยนแปลงนโยบาย

หากแก้ไขนโยบายนี้ จะปรับวันที่ด้านบน และแจ้งในแอปเมื่อการเปลี่ยนแปลงมีผลต่อวิธีใช้ข้อมูลของคุณอย่างมีนัยสำคัญ
